# Vesktop

Vesktop is a modified client of Discord, it's definitely not working with
Discord's ToS.

## Pirotheme

Custom theme based on [Clear Vision's v6 theme](https://github.com/ClearVision/ClearVision-v6).

### Arch

To install:

```bash
cp clearvision.css piro.theme.css ~/.config/vesktop/themes
```
